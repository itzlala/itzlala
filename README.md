## Proyectos destacados

### [ReleasePilot](https://github.com/itzlala/releasepilot-backend-challenge)

API para gestionar promociones de versiones a través de un pipeline `DEV → STAGING → PRODUCTION`.

- Java, Spring Boot, PostgreSQL, RabbitMQ y Docker Compose.
- Arquitectura hexagonal, CQRS y Transactional Outbox.
- Consumidores idempotentes, reglas de dominio y control de concurrencia.
- Agente de notas de versión con ciclo real de tool calling y pruebas automatizadas.

### Nexo Inventory

Sistema full-stack para administrar activos, responsables y ubicaciones de una empresa.

- [Aplicación web](https://github.com/itzlala/nexo-inventory-web): Angular, TypeScript, Angular Material y diseño responsive.
- [API REST](https://github.com/itzlala/nexo-inventory-api): ASP.NET Web API, C#, SQL Server y Swagger.
- Autenticación JWT, rutas protegidas y operaciones completas de inventario.

## Cómo trabajo

- Modelo las reglas importantes dentro del dominio y hago explícitos los casos de error.
- Diseño contratos de API claros y separo responsabilidades entre capas.
- Acompaño el código con pruebas, documentación y entornos reproducibles.
- Documento decisiones y trade-offs, no solamente instrucciones de instalación.
